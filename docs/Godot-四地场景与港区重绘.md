# 四地场景与归帆港升级

低语森林、余烬峡道、月沼遗境、风葬海崖采用已确认的四宫格方向，统一晨星镇的绘画质感、等距视角与建筑尺度，分别保留森林、峡谷、湿地和海崖的生态特征。晨星镇、归灯王城及室内原画不在本轮重绘范围。

## 场景组织

- 19 处原功能建筑采用 19 种独立图像；较小的旧建筑体量按用途校准，扩大时保留原服务入口，重新连接支路。风车移至农田侧方，减少对主街视线的遮挡。
- 四地装饰按生态与用途布置：林木和麦田、矿业作业区、湿地岸线与残墙、海崖及港区。主街、入口、任务人物和桥面优先留空；实体基底接入碰撞。
- 归帆港是完整设施区：港务所负责原功能，货栈、鱼市、修船棚独立落地，港区道路连接装卸场、滨水通道和三段栈桥。吊机靠近装卸位置，船只泊于水域，货物和渔具避开作业通道。三名环境人物沿安全路线活动，减少动效时冻结。
- 材质采用各地区独立的地表、道路和码头木纹，启用 mipmap；新素材使用线性 mipmap 缩放。原有四时段光照、距离裁剪与局部光源预算继续生效，HUD 独立于环境光。

## 兼容

新增区域配置字段 `artVersion`、`ambient_residents` 和港区 `harbor` 只用于场景表现；栈桥可声明 `material: wood`。附属设施继续使用已有装饰碰撞机制。无需外部 API，不修改存档格式。

建筑 ID、任务入口、原服务和剧情推进保留。出生点等合法旧坐标保留，被扩大建筑或新设施占用的坐标沿用实际通行检测迁到附近安全位置。地图与小地图使用实际场景重新烘焙，仅更新本轮四地。

## 制作与验收

原稿与提示词位于 `art-source/regional-redraw/v1`。先运行 `tools/package-regional-art.cjs`，再运行 `tools/design-regional-redraw.cjs`，导入后运行 `res://tests/regional_redraw_review.gd` 生成真实地图和截图。重新打包以更新地图文件大小，之后再次导入并构建 Windows/Web。

`regional_redraw_acceptance.gd` 已接入原生回归，覆盖实际任务/服务落点、道路净宽、19 种独立地标、港区设施与栈桥可达、附属建筑碰撞、旧档恢复和环境人物的减少动效行为。原有剧情、战斗、存档和五地探索回归继续执行。

实机检查位于 `artifacts/godot/regional-redraw-review`，包括四地 720p/1080p/4K、19 处建筑细节、四地夜景、实际地图和港区全景。运行 Windows 独立发行包和 Web 浏览器检查后交付。
