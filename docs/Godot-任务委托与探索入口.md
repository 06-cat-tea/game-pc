# 任务接取、公会委托板与探索入口

2026-10-17，Godot 电脑版。发行名称仍为 `灰烬边境.exe`，存档格式仍为原生 v1，手机版未调整。

## 玩家使用说明

主线自动追踪。其他委托要明确接取，完成目标后显示“可交付”，再返回指定委托人或公会板领取奖励。J 打开日志：可交付在前，进行中的主线优先，其余按接取先后排列；完成任务收在最底部“已完成（数量）”，默认折叠，展开可查看委托人与奖励。完成记录不再提供待办按钮。纯旅途日志在“记录”分类。

进入边境公会，靠近“委托公告板”按 F 或用鼠标打开。板上有全部、战斗、居民、采集、探索五类。材料可使用已有库存，只在交付时扣除。居民委托也可向本人接取，两处共用记录；居民目标完成后回孩子本人交付，战斗和公会采集回板交付。同行、觉醒、研究和制作订单仍从对应人物或建筑明确接取。

晨星镇新增小洛、阿芽、小铃。小洛在公会附近，先“团团躲哪了”（旅店爪印→橘猫团团，20经验/10金币），再“安静的马厩”（安抚黑白犬阿墨，20/12）。阿芽在杂货铺附近，先“雪球的午餐”（嫩叶喂白兔雪球，15/8），再“丢失的小药包”（灰猫点点身旁取回药包，25/12）。小铃在礼拜堂附近，先“咕咕的新食盆”（放食盆→喂母鸡，15/8），再“飞回来的信”（麻雀豆豆→礼拜堂信箱，25/12）。第二份在第一份交付后开放。嫩叶、食盆、饲料、药包、信笺均为任务记录中的专用物品，不进入可交易材料。动物可以观察、抚摸和进行当前任务互动；打开菜单暂停巡游，夜间仍可找到。

镇内有三处晨露药草、两处浅层矿样，各只能采一份，读档不刷新。公会“边境药草清单”沿用原建筑服务的3草药、20经验/18金币，只发一次；“公会矿样征集”为2矿石、20经验/14金币。巡径清剿和旧渠清理在对应入口发现且路线解锁后发布，接取后的普通战斗胜利才计数，奖励分别为25经验/15金币和35经验/20金币。训练、觉醒回响与精英、首领不计入这两份普通战斗委托。

## 十五个探索入口

| 所属地区 | 独立入口旁的建筑 | 三段路线（由前至后） |
|---|---|---|
| 晨星镇 | 北门、旧渠检修口、公会 | 城墙巡径、旧城地下渠、公会试炼场 |
| 低语森林 | 林间小屋、苔痕遗迹、月井 | 银叶深径、古根洞窟、月井下层 |
| 余烬峡道 | 商队集散场、深层矿坑、余烬要塞 | 栈道岔路、灰炉旧矿层、熔核腹地 |
| 月沼遗境 | 沉没神殿、王陵、净水祭坛 | 沉没神殿内殿、王陵深层、黑水封印庭 |
| 风葬海崖 | 归帆港、沉船遗址、灯塔 | 潮间礁道、沉船货舱、无旗船甲板 |

旧渠检修口独立设在晨星镇 `(22.5,14)`，与月沼紫晶地牢脱离。入口与原建筑用途分开，原建筑仍能进入或使用服务。

在所属大地图中靠近入口三格内，入口位于当前视野且中间没有阻挡，才算发现。打开地图、建筑详情或点选地标不会发现入口。发现首段后发布当地三段连续调查，可在入口、委托人或公会板接取；没有自动接取。尚未发现的后续目标只提示寻找线索。未接取也可探索、搜集补给、解锁通道；新委托不追溯接取前战斗和调查，接取后需再实际调查。任务定位优先带往实际入口，不直接跳进未发现的路线。每张路线图都有返回所属地区的出口，回到对应入口旁；原有前往下一段的通道与调查条件保留。

## 工程与兼容

`godot/data/quest-catalog.json` 是41份支线、调查、个人及建筑任务的目录；旧文案、奖励和步骤引用原 `narrative.json`、`content.json`、`progression.json`，不复制维护。`world-interactions.json` 保存15入口、3孩子、6动物、5资源点和4任务调查物。场景、地图、定位与返回落点读同一入口定义。

`QuestRuntime` 统一接取、推进、状态与交付；已完成标记在奖励和信号之前提交，防止重复点击、跨入口或读档重复领奖。主线事实独立记录，托伦与艾拉具有单独的主线交谈选项，不要求顺便接支线。觉醒仍经完整的开场、调查、试炼和收束解锁，TP规则不变。

旧档已有任务迁为已接取，保留原进度和已领奖状态。同一地图中读取另一份存档也会恢复对应落点和采集标记，避免残留上一档的场景外观。升级前保存 `*.before-quests-v1.json`（导入另有 import-before-quests-v1.json），不改存档目录、不重置角色成长、TP与觉醒。非法任务状态、专用物品和入口记录拒绝载入。

三名孩子的全身原稿、六动物动作图集、提示词与参考说明在 `art-source/town-life/v1`。24张透明运行 WebP 在 `godot/assets/town-life`，由 `tools/native-package-town-life.cjs` 从本地原稿打包。原有角色与移动素材保持原映射。
