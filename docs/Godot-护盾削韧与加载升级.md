# 手绘加载资源与战斗策略 v2

本次仅升级 Godot 原生电脑版。保留四人回合制、原剧情与成长、七人觉醒及独立训练快照。原生 v1 存档格式和用户目录保持兼容。

## 美术与加载

新增十张 1920×1080 加载插画：晨星镇、低语森林、余烬峡道、月沼遗境、风葬海崖、归灯王城，以及启程、营地、遗迹、战前整备。最终版采用日式西幻手绘背景，水彩、水粉与可见线稿，每张集中一个视觉焦点，减少建筑、道具和装饰堆叠。

- 最终原稿、完整提示词及来源记录：`art-source/loading/v2/`。`v1/` 保留细节较密的初稿作为制作记录。
- 运行图：`godot/assets/loading/`；展示及预加载配置：`godot/data/loading.json`。
- 加载先显示画面，再准备资源和构建场景；不显示虚构百分比。减少动效关闭淡出，期间锁定移动与重复提交。失败可重试、返回或按 Esc 退出。
- 启动、读档、新旅程、区域旅行、室内进入、营地休整和战斗准备均有对应入口。探索中的突发战斗由会话变更统一接入战前画面。

保留原有 38 张彩色装备插画，补充 30 个物品、材料、属性、状态和阵型符号。新符号来自 Game-icons.net，作者为 Lorc、Delapouite 和 sbed，采用 CC BY 3.0。逐项链接、作者和修改记录在 `godot/data/item-icons.json`，原 SVG 与官方源包保存在 `art-source/item-icons/v1/`。随发行包提供 `LICENSE-Icons-CC-BY-3.0.txt`；这部分素材不适用游戏原创内容的 CC0 声明。

## 战斗规则

### 护盾与护卫

护盾独立于生命和敌方韧性。每个技能来源分别记录盾量和剩余行动次数；受伤时所有来源同时扣除该次伤害，实际吸收量取最高盾量，溢出才扣生命。持续伤害也经过护盾，但有盾不代表免疫负面状态。

同来源重施取新旧较高值并刷新该来源时间，不延长其他来源。托伦羁绊及专属大招明确允许累加自身来源，最多达到目标最大生命的 60%。守望阵实际增加 15% 生成盾量。完全吸收伤害时不触发生命受伤 TP。

托伦羁绊还提供持续两次托伦行动的代受护卫，避免由较慢队员触发时在托伦紧接着行动前失效。星盾协奏提供护盾及每人每轮一次的反击。

### 属性、弱点与韧性

本作的固定属性循环为：**火焰 → 物理 → 星辉 → 圣光 → 毒素 → 火焰**。攻击克制目标主属性时 ×1.25，反向受克时 ×0.8，其余 ×1。首版只有敌人具有防守主属性，我方转职不会额外改变承伤属性。

弱点列表单独决定能否削韧：非弱点攻击仍能扣护盾和生命，常规情况下不能削韧，也不因“命中弱点”再额外叠加增伤。技能说明和选中目标预览使用同一套规则；单体攻击受护卫拦截时，预览按实际代受目标计算。

新战斗默认韧性为普通 30、精英 60、首领 90。匹配弱点时，普攻削韧 10，单体技能 20，群攻每目标 10，大招每目标 30。每个技能可单独配置。持续伤害、反击与追击不重复削韧；破甲不默认绕过弱点。

击破清除蓄力，产生不暴击、不递归的额外击破伤害，进入受伤增加 25% 的窗口，并跳过下一次行动，再下一次行动开始恢复韧性。首领恢复后须完成一次正常行动才能再次因击破跳过行动，避免连续控制锁死。

| 击破属性 | 附加效果 |
| --- | --- |
| 物理 | 流血 |
| 火焰 | 灼烧 |
| 星辉 | 易伤 |
| 圣光 | 虚弱，输出降低 20% |
| 毒素 | 中毒 |

### 阵型、羁绊和协奏

- 均衡增加 25% 追击支援伤害及有效配合的协奏收益。
- 突击保留伤害与承伤 +10%；前排每轮首次弱点攻击额外削韧 10，攻击已击破目标再提高 15% 伤害。
- 守望保留承伤 -10%、伤害 -5%、治疗与护盾 +15%；加强护卫减伤，并让前排护卫保护后排。
- 战中变阵消耗当前角色一次行动，每轮全队最多一次，不获得 TP 或协奏；本轮行动顺序不重排，战后保留选择。训练退出仍恢复原快照。
- 六同伴羁绊按身份分别提供击破封印、叠盾护卫、治疗净化、标记收割、倒地救援、毒伤及回蓝；保留好感 60、10 MP 和个人冷却条件。
- 双人协奏分别负责星盾反击、回春净化、蚀毒引爆；冷却全队按组合共享，以全局轮次递减。
- 协奏由实际弱点削韧、击破、代受和追击积累，每条指令最多 30。空治疗、换位和变阵不能刷取。

自动战斗会考虑弱点、护卫、治疗和蓄力目标，保留原有战术与自动大招开关。变阵、个人羁绊和双人协奏由玩家决定。

## 遭遇、接口与存档

剧情敌群调整攻击折减，按角色区分弱点与主属性。区域挑战加入护卫、治疗者或侧翼远程；首领半血换阶段并预告范围重击。区域精英第 4 轮开始预告逐轮增强的狂热重击，要求及时集火、削韧或防护。新敌人配置不会重新生成已经存入旧档的进行中敌群。

集中规则位于 `godot/data/battle-rules.json`。技能资源新增 `toughness` 与 `shield_rule`，保留明确的 `element`；变阵命令沿用 `BattleCommand` 的 action/skill/turn 接口。事件新增削韧、吸收、盾破、变阵及克制倍率；预览返回实际目标、倍率、削韧与击破判断。

存档增加战斗规则版本、分来源护盾、击破恢复标记、首领控制保护、变阵轮次和组合冷却。旧档读取或导入前保存 `.before-combat-v2.json` 备份；旧战斗保留生命、法力、资源、敌人和随机流，将旧护盾迁入独立来源、旧架势单位乘十。非法字段拒绝读取。

## 验证与交付

- `pnpm test`：原生规则、剧情、输入、界面、旧档与训练回归，包含战术升级专项。
- `pnpm godot:strategy-balance`：700 场固定种子对照；两队、推荐等级内技能、相同普通装备与消耗品、初始 TP 为零。普通自动胜率至少 85%；按精英、首领组聚合，主动策略至少 80%，比相同内置自动策略提高至少 25 个百分点。每个遭遇和队伍的原始结果也完整保留，不将组内平均值视为每场保证。
- `pnpm godot:strategy-check`：十张图尺寸、原稿、38 张装备保留、30 个符号及来源、许可检查。
- 独立复制工程后执行完整原生回归、PowerShell 导出和发行程序冒烟验证；实际 GPU 截图检查战斗、背包与加载界面。

验收报告位于 `artifacts/godot/native-acceptance.json`、`standalone-acceptance.json`、`standalone-build.json`、`strategy-balance.json`、`strategy-assets.json` 和 `strategy-review/`。原剧情文本基准校验保持通过。
