# Windows 试玩版安装构建

在电脑版工程根目录运行：

```powershell
pnpm build:demo
pnpm test:installer
```

`build:demo` 从 `godot/` 复制独立试玩工程，禁用制作插件，设置试玩名称、版本和独立用户目录，运行原生回归与资源检查后导出并编译安装器。不会覆盖正常电脑版配置及 `artifacts/godot/windows/`。使用本地 `artifacts/godot/engine/godot.exe`，也支持 `GODOT_PATH`。

NSIS 3.12 便携编译器和原始 ZIP 保留在 `tools/vendor/`，脚本编译前核对官方 SHA-256。编译器及制作脚本不进入玩家安装目录。

产物在 `artifacts/installers/`：安装 EXE、SHA256SUMS、安装与存档说明、构建清单。`work/` 保存独立源码、导出文件与日志，用于验收。仅分发安装 EXE 即可；校验文件与说明可一并提供。

试玩配置只写入临时副本：名称「灰烬边境：星陨纪事 · 试玩版」，版本 `7.3.0-demo.20261017`，原生 EXE 的四段文件版本 `7.3.0.0`。剧情内容完整，存档格式保持原生 v1。试玩存档位于 `%APPDATA%\AshenFrontierDesktopGodotDemo\saves`，原电脑版目录不会自动读取或迁移。

安装器只请求当前用户权限，安装登记保存在 HKCU 的 `AshenFrontierDesktopGodotDemo` 卸载项。默认安装在 `%LOCALAPPDATA%\Programs\AshenFrontierDemo`，开始菜单分组「灰烬边境试玩版」。文件清单同时用于打包和卸载；不递归删除目录，不删除存档。EXE 或 PCK 正被占用时终止静默安装/卸载，交互模式可退出游戏后重试。

`test:installer` 会执行真实安装、重装和卸载，并临时创建当前用户快捷方式与卸载登记；发现已有试玩安装或同名快捷方式时停止，防止影响用户环境。测试游戏的 APPDATA 重定向到工程内隔离目录，只有自行启动的无进度测试进程会在占用检查后关闭。测试结束后移除测试入口，保留工程内报告和测试档。

验收报告明确记录实际测试主机，不把本机结果当作所有 Windows 版本或显卡的验证。发行包默认未签名，未自动上传或发布。
