# 灰烬边境 · 角色觉醒与星轨交互

本轮仅修改纯 Godot 电脑版，保留原主线、人物身份、服装、手机版与原生 v1 存档命名空间。Windows 包位于 `artifacts/godot/windows`，运行 `灰烬边境.exe`，同名 PCK 与许可文件保持在旁。

## 修复与界面

- 列表局部更新时移除旧主题覆盖，取消业务选中后恢复普通样式。金色定位标、浅金窄底及四芒星表示选中，悬停和键盘焦点各自独立。背景、立绘、滚动与焦点保留。
- 已读话题、已完成的一次性任务和已招募入口从当前交谈列表隐藏；旧档往事选择也视为已读。进行中的委托显示进度，商店、赠礼和休息保留；历史仍可查阅。
- NE／NW 原稿与五帧映射已纠正，并记录修复标记，重新打包不会被旧缓存覆盖。屏幕投影逆变换保留；墙边按屏幕水平、垂直分量滑动，不产生反方向分量，停止保留实际最后朝向。
- HUD 使用统一纸色圆章、香槟金细环、深蓝灰线图与角落键帽。详情页使用原创星轨、章印及分隔线；角色与战斗增加 TP 和觉醒追踪。

## 个人 TP 与觉醒

每人 TP 为 0–100，完成觉醒后才开始积累。普通成功主动行动 +20；实际受到敌人直接生命伤害 +10，每轮上限 +20；主动造成架势击破再 +10，每条指令最多一次。大招、自身持续伤害、追击和无效指令不产生行动 TP。大招消耗 100 TP 与当前行动，不消耗 MP。TP 跨战、旅行、休息和转职保留；休息不补，倒地清零。全队协奏独立运作。战术页“允许自动大招”默认关闭。

旅人完成序章后开放觉醒；同伴需已经入队且个人委托完成。旧档满足前置条件也必须经历新觉醒故事。每段包含开场交谈、两处线索、六级回响试炼、收束交谈。试炼强制对应角色，提供 100 TP 教学；胜利只推进故事，收束后才解锁纹章与大招，不额外奖励永久属性。随时使用“退出回响试炼”恢复进入前的剧情快照。

## 特效、数据与存档

58 项主动技能均接入施法、命中、治疗、护盾或状态表现；斩击、箭轨、星辉、火焰、毒雾等使用独立表现层。七人大招具有原创 SVG 纹章、配色与节奏。普通行动约 0.55 秒，大招约 0.9–1.1 秒；减少动效为约 0.12 秒，保留命中、治疗与状态提示。

事件携带动作、技能、元素、施法者、目标和唯一编号；编号随战斗存档递增，不额外消耗随机数。重建同页不会重播，重复包不会打断正在播放的特效。

`data/progression.json` 维护新增剧情、建筑服务和大招定义；原有 9,157 条文本基准保留，新增 581 条标量记录追加独立基准。运行场景由 64 增为 66。v1 新增个人 TP、觉醒、建筑服务、自动大招和战斗事件字段，缺失时补默认值，非法数值拒绝。首次升级（包括备用档恢复、JSON 导入）保留 `before-tp-v1` 原始备份，训练与试炼不写入剧情存档。

## 验收与证据

### 旅行储物柜提示页热修复

真实 Enter／空格退出无选项对白时，`advance()` 会先将对白节点从界面树移除，旧代码随后调用 `get_viewport().set_input_as_handled()`，产生空对象错误。现已在导航前完成事件处理，正文点击也先接收事件，避免关闭后输入继续传到场景。

新增六种真实输入回归：F 打开储物柜后，分别通过 Enter、空格、正文、底部返回、Esc、顶部返回退出，检查探索输入恢复、物资与存档保留。`native-dialogue-repro.log` 记录修复前错误，`native-dialogue-input.json` 为修复后结果。本机独立验证各操作约 42–68 ms、写档约 3 ms、返回晨星镇约 55 ms；这些是测试环境测量，尚未重现玩家报告的长时间停顿。

发现运行中的旧游戏始于 19:13，早于 21:10 的资源包更新。运行中的进程不会热更新，新包应在正常退出旧窗口后替换并重启；本次先在独立目录构建、验收，避免改写仍在使用的 PCK。

热修复后原生及独立工程各通过 **4,272** 项检查；从发行 PCK 加载代码的六种输入测试共 **20** 项通过（使用匹配的 Godot 编辑器运行时及外置测试驱动，驱动不随发行包提供）。玩家确认退出后已替换原发行目录，保留 `artifacts/backups/windows-before-dialogue-fix-20261016`。此前被旧进程锁住的 109 MB 临时 exe 也已删除。Node 与 PowerShell 导出入口新增运行检查，阻止覆盖仍在使用的 exe/PCK。
