# 晨星镇美术样板

## 统一风格

原创日式手绘奇幻 RPG，与现有二次元人物协调。轮廓清晰但保留轻微手绘变化，体块简洁，明暗克制。使用有修补痕迹的木梁、暖灰泥、风化石材、陶瓦和旧铜；细节表达建筑用途与地方生活。

色彩以鼠尾草绿、暖灰、陶土红、靛蓝和少量古铜为主。照明来自左上方。避免塑料高光、密集金饰、无意义尖塔、过度锐化和用随机纹理掩盖结构。

## 提示词与原图

`prompts.json` 保存 86 项独立提示词：11 栋建筑、12 项环境物件、5 种地面材质、14 张可玩场景、38 件装备图标及 6 张地方加载画面。

生成使用内置 imagegen。每项资产单独生成，原图保存在 `sources/`，运行资源使用 WebP。旅店是首张材质参考；其他建筑及后续环境物件引用旅店原图仅用于统一材质和笔触。

## 生产约束

- 建筑：正交斜视，以游戏 17:9 地面投影作为参考；完整透明轮廓，不生成展示台、草地底座、整片投影或界面文字。
- 地面：无透视的俯视材质，生成草地、石路、土、砖和碎石；运行时在同一地面坐标系中重复与投影。
- 环境：完整透明主体，不带地块；以木、石、布和旧铜为主要材料。
- 场景：16:9 开放前景的斜视空间；提示词明确交互物件的图像位置，出口及中间行走区留空。
- 装备：单件透明主体，小尺寸清楚；稀有度边框和强化文字在 UI 中绘制。
- 加载：六地各一张 16:9 地方插画，下方留出文案区域，不把进度条、地名或文字画进图片。

## 晨星镇生活与建筑

镇民靠转运灰炉铁货、林地药草、海岸灯油与旅人补给生活。旅店、公会和礼拜堂共用失散者名册。钟塔负责报时，学院用于测向教学，接待厅用于登记与导览；三者的建筑造型按各自用途区分。

建筑、美术资源与存档中的地点身份分开。晨星镇使用 `town-` 前缀的专属素材；其他五地继续使用原来的资源。接地锚点、入口参考、占地和阴影参数在 `catalog.json` 中记录。

`layouts.json` 保存按最终绘景校准的交互锚点、家具地面占地和遮挡轮廓，坐标以 480×270 逻辑画面记录。角色可以沿中央空地到达全部交互物件，长桌、座椅、星盘和机芯不允许穿过。生成图在物件位置上与提示词有差异时，以校准后的记录作为运行依据。

建筑接触阴影绘入地面缓存，避免每帧重复模糊。土石边缘分层渐隐；人物立绘保持原素材，晨星镇室外按建筑门窗比例调整绘制尺寸。

## 重建与检查

在项目根目录使用：

```powershell
node tools/art-v3.cjs jobs
node tools/art-v3.cjs import <资源键> <imagegen 原图路径>
node tools/art-v3.cjs masks
node tools/art-v3.cjs contacts
node tools/build-game.cjs
node tests/art-v3-layout.cjs
node tests/art-v3-acceptance.cjs
```

`init` 重新输出提示词和目录；`import` 只负责保留原图、裁去透明外边距、缩放和压缩，不调用图片生成 API。
