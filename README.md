# 灰烬边境：星陨纪事

## 独立电脑版工程

电脑版仓库：[06-cat-tea/game-pc](https://github.com/06-cat-tea/game-pc)。本仓库只发布电脑版，手机端暂未发布，因此标题页与设置页默认隐藏手机版切换入口。

两端互不隶属、互不干涉。以后各自修改、测试和发布，不自动同步代码、资源或进度；具体约束见 AGENTS.md。

本目录是一套完整的独立 Git 工程，含独立代码、运行资源、原画与可编辑模型，可单独克隆、构建和部署。固定电脑布局，使用 WASD / Shift / E / Tab 与鼠标操作，触控电脑仍保持电脑布局。

直接打开 frontier.html 即可游玩。开发需要 Node.js 20 或更高版本及 pnpm 11：

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run preview
pnpm run test:setup
pnpm test
pnpm run test:regression
pnpm run test:standalone
```

预览默认使用 8080 端口，可通过 pnpm run preview -- 8081 指定另一端口。测试默认使用 Playwright Chromium，也可通过 CHROME_PATH 指定浏览器。

本端存档键为 ashen-frontier-save-v3-desktop；首次启动可从同来源的旧档继承进度，此后两端分别保存。跨设备、跨域名或另一端之间转移进度，请在设置中导出、导入 JSON。

js/deployment-config.js 中的 mobile 默认为 null；将来手机端正式发布后，可在此填写它的独立地址来显示切换入口，地址相对于 frontier.html。静态发布不需要安装开发依赖。

常规运行、构建和验收不依赖其他工程。历史 Git 对比与资源恢复工具需要原始历史；下文保留原版本的功能和制作记录。


原生 JavaScript 与 Canvas 的暗色奇幻 RPG。直接打开 `index.html` 或 `frontier.html` 即可游玩，无需构建、服务器、账号或外部运行时资源。场景分辨率为 1920×1080，本端使用完整 16:9 游戏区域，所有界面都位于游戏画面内部，固定使用电脑布局。

原统一工程地址：https://06-cat-tea.github.io/game/frontier.html

## 操作与功能

- WASD / 方向键移动，按住 Shift 跑步，靠近目标按 E；鼠标点击 NPC、建筑、室内物件进行交互。
- 右键对象打开对应菜单，空白场景右键访问常用功能；手机长按 450ms 或点击“更多”按钮打开相同菜单。
- 手机左下使用固定移动摇杆，右下为交互、药剂和快捷菜单；桌面隐藏摇杆，使用 WASD / 方向键移动。打开菜单、对话或功能面板会暂停移动；松手、取消触控、失焦和旋转会清理输入。
- 左上显示小地图、地点、时段和任务提示；右上为背包、任务、队伍、更多，右侧显示最多三位支援同伴，底部显示生命与法力。附近行动、居民、事件及挑战可从“更多”进入。
- 电脑探索时按住 Tab 打开八项快捷轮盘，移出中央选择功能，松开执行；中央松开或 Escape 取消。点击右下菜单按钮后可直接点击项目。对话与面板中 Tab 正常切换焦点。
- 功能面板使用分类、搜索、分页和并排详情，按实际空间减少每页数量；桌面最多 6 项、触控布局最多 4 项。主要操作和翻页按钮固定可见，关闭后返回原场景，场景 Canvas 始终保持挂载。
- 在“设置与存档”中点击“全屏 / 横屏”可进入全屏并尝试锁定横屏；不支持方向锁定时继续使用内部旋转布局。页面不滚动，详细说明可以在游戏内面板中滚动查看。
- 六区域、82 个独立建筑地标、51 个可进入的内室、66 位居民。五个旧区域扩大至 64×48 格；归灯王城为连续的 96×72 格，包含九街区、52 栋建筑、26 处内室和 40 位居民。保留原有 38 张背景与十五条冒险路线，王城采用独立地形、建筑、街具与家具绘制。
- 保留“星钟谜语”及旧居民委托；新增五条两阶段区域支线、10 个一次性选择事件、五名精英、五项区域挑战和“归灯之后”收尾任务。
- 六职业，每职业三分支、每分支五节点，共 90 个技能；四个主动技能配置位、共用技能点和免费确认重配。刺客、牧师与炼金师通过夜岚、艾拉、瑟琳的导师任务解锁。新增十二件职业武器与饰品，接入制作及 +1～+3 强化。
- 六名同伴、三个自动支援位；均衡／突击／守望阵型，输出／保护／资源保留战术。支援技能随主角等级 1／4／7 开放，60 好感解锁羁绊；三组双人协奏使用共享协奏条。
- 一至三名敌人的战斗，目标选择、群攻、护卫、治疗、召唤、精英招式轮换与 Boss 阶段。灼烧、中毒、流血、易伤、破甲、再生、沉默、护盾显示来源及回合；Boss 受硬控制后获得两回合控制免疫。
- 十五张冒险子地图包含调查、补给、选择事件及遭遇；五条三阶段路线调查、六条两阶段个人任务与五项独立高阶挑战。任务详情可定位入口，地点地图可切换区域总览／区域地点，旧路线从“更多 → 冒险路线”进入；支持镜头跟随、缩放与沿入口返回。

## 大场景与归灯王城

晨星镇的王城接待厅新增“前往归灯王城”入口，也可通过世界地图旅行；南门城门署提供返回晨星镇入口。跨区域旅行沿用两个时段的消耗，城市街区之间的地点跳转不消耗时间。公共区域全部开放，无需主线解锁。

九街区为南门驿街、王都大市、蓝瓦匠街、星院书苑、王冠宫庭、河港商埠、灯誓圣区、旧城民巷、翠庭水园。建筑有独立名称、占地、碰撞与交互；水渠不可穿越，三处桥梁连接两岸。52 栋建筑中 26 栋开放内室，其余建筑提供外观、地点介绍或沿街生活内容。没有城市敌群、随机遭遇或调查奖励。

打开“地图 → 区域地点”查看街区或现有地标，点击节点或分页列表即可前往安全落点；内室中使用地点导航会退出内室。地图显示道路、建筑和当前位置，不显示等级、敌群、调查目标或探索奖励。五个旧区域重组已有地点，外围补充道路与自然景观，本次未额外增加旧区域建筑和居民。旧战斗路线改从“更多 → 冒险路线”进入，关联建筑入口和任务定位继续可用。

城市服务包含导览、档案、音乐、补给交易和休息。干粮 20 金币、药剂 28 金币；休息消耗一份旅行补给和一个时段，沿用原生命／法力恢复比例，每日一次。导览、阅读、音乐与地点跳转不增加经验或推进旧任务。

继续使用 v6 存档，扩展位置、城市内室返回点、居民好感与选择均可保存；非法坐标或落入不可通行物中的位置会恢复到安全点。`js/world-regions.js` 统一边界与安全落点，`js/world-terrain.js` 缓存地形和外围景观，`js/city-content.js` 管理城市内容，`js/city-renderer.js` 绘制建筑细节、人物、街具和家具。

`node tests/city-acceptance.cjs [可选 URL]` 检查王城数量、通路、建设预留、全部建筑命中与内室出入、城市服务、对话导入导出、异常存档、和平地图及六种视口。修改清单、截图和结果见 [王城验收说明](王城-验收说明.md)。

## NPC 分支对话

66 位居民各有日常闲聊、区域传闻和个人往事，六位同伴另有深入话题，共 204 个话题。王城 40 位居民新增 120 个身份相关话题。个人往事在好感 20 时开放，深入话题在好感 40 时开放。开场根据时段、主线及委托进度变化；画面突出人物肖像，底部显示当前对白，右侧为“聊聊、委托、服务、赠礼”，右上可告别。各入口按人物能力显示，话题和委托按空间分页，每页最多四项。

点击话题后以约每秒 25 字逐字显示；第一次点击对白或按 Enter / 空格显示完整当前段，第二次推进。长对白按实际宽度和高度分段，电脑最多两行、手机最多三行，无需滚动；“减少动效”启用时整段显示。方向键切换选项，Tab 切换焦点，Escape 返回上一层，在交谈入口时退出。返回话题不会再次领取聊天好感。

自动播放默认关闭，开启后在整段显示完毕时等待 1.5～5 秒再推进；遇到回应选择、菜单切换、失焦或旋转会暂停，不会自动确认回应、委托或赠礼。服务打开独立交易面板；赠礼先显示材料与消耗，再由玩家确认，完成后返回交谈入口。

每日首次交谈好感 +4，每日赠礼好感 +6。每人的往事有一次关系选择，支持回应 +2，中性回应 +0，选项会提前说明。首次回应立即保存并锁定，重读沿已选分支展示；其他话题的选择仅影响当次对白。阅读不会消耗时段或改动任务奖励。完整读完才标记“已读”，中途退出后再次打开从话题首页开始。

对话记录沿用 v6 存档，旧档无需重开；导入、导出和重载均保留已读与选择，当前阅读句数不保存。赠礼会显示具体材料、持有数量与每日状态，地区服务显示实际消耗、收益及可用条件。

## 米拉 Live2D 对话立绘

米拉使用在 Cubism Editor 5.3.04 FREE 中制作并导出的真实 Live2D 模型，包含眨眼、随逐字对白变化的口型、呼吸、轻微转头、身体、头发及衣饰摆动。赠礼时微笑，往事及深入话题使用严肃表情，其他交谈使用中性表情。主角回复切换到主角现有头像，等待回应选择时保持居民。其他角色暂时沿用现有头像。

官方 Cubism SDK for Web 固定为 5-r.5，运行资源本地打包，直接打开 HTML 仍可使用。模型加载中、WebGL 失败或开启“减少动效”时显示透明膝上备用立绘；退出交谈清理实例，页面隐藏时暂停。

`assets/characters/mira/` 保存 14 层 PSD、可编辑 CMO3、MOC3、模型描述、2048px 单张纹理、物理与三种表情文件、原画和分层素材。制作提示词见 `prompts.json`，重建及验收见 [Live2D 验收说明](Live2D-验收说明.md)。`node tests/live2d-acceptance.cjs [可选 URL]` 检查真实模型加载、162 组动作组合、口型与表情、清理及六种桌面/手机尺寸。

## 存档兼容

v6 自动存档沿用 `ashen-frontier-save-v3` 存储键，兼容 v2～v5。迁移前按原版本保留一次备份；旧角色、主线、任务、装备、强化、材料、技能点和已学技能保留，旧战斗迁为单敌人结构。旧同伴羁绊按每级 20 点迁入 0～100 好感。旧档可证明的成就允许领取奖励，未记录的探索项目从未发现开始。新增职业解锁、技能配置、阵型战术、子地图位置与返回栈均可保存恢复。
