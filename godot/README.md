# 灰烬边境：星陨纪事 · Godot 电脑版

用 Godot 4.7.2 打开 project.godot，按 F5 运行。同一套内容支持 Windows 原生包和单线程 Web 导出，采用 Compatibility 渲染。Windows 包可离线运行；Web 版在电脑浏览器中加载完整游戏，均不依赖 Node.js。

[网页版入口](https://06-cat-tea.github.io/game-pc/) 使用键盘鼠标，点击游戏画面获得焦点。本地 Web 导出使用上级目录的 pnpm build:web 与 pnpm preview:web；HTTP 服务地址见终端输出，不能直接以 file:// 打开。

## 操作与表现

WASD／方向键对应屏幕八方向，Shift 为 1.8 倍跑步，F 交互。点击场景可寻路，键盘接管寻路；八向动画每向包含站立与四帧行走。碰撞在屏幕方向上滑动，失焦清理输入。

按住 Tab 打开居中的图标轮盘，选择高亮方向后松开执行；中央松开、Esc 或失焦取消。Windows 运行时鼠标自动居中，浏览器按实际鼠标位置选择。B 背包、C 角色、J 任务、M 地图、L 队伍，同键关闭，异键切页。面板内 Tab 切换焦点，Esc 逐级返回。战斗 1–4 选技能，E 选首个已配置技能，Q 选大招，点击目标、Enter 确认；选择本身不扣资源。

角色、背包、技能、地图和战斗选择更新当前界面，不重复播放整页淡入。七名主队角色有常态、微笑、严肃全身立绘；角色页与战斗显示全身，对话固定取景。赠礼使用微笑，深入与往事话题使用严肃表情。

## 旅程

从晨星镇开始，到钟塔结识米拉，在礼拜堂完成艾拉的守灯委托。调查城墙巡径、地下渠和公会试炼场，完成序章后与米拉接取星图委托。森林碑文、矿车护送、沉没神殿与五地调查最终通向「归灯之后」。地图可旅行六地；当地行动、人物、世界志和成就由终端进入。

每名角色独立成长、装备和冷却。最多四人出战，前后排影响合法目标；六职业技能、羁绊与协奏、制作强化、训练隔离保持原规则。公会训练退出后恢复完整剧情快照。

新增觉醒从角色页、终端或对应建筑进入：旅人、米拉在晨星钟塔；托伦在灰炉锻坊；希薇在林间小屋；夜岚在灰盾兵营；艾拉在净水祭坛；瑟琳在云上观星城。旅人需完成序章，同伴需已入队且完成个人委托。旧档满足条件时开放新故事，仍需完成开场、两处线索、六级试炼和收束才能解锁。

觉醒后个人 TP 为 0–100：成功普通主动行动 +20，受到敌方直接生命伤害 +10、每轮最多 +20，主动击破额外 +10、每条指令最多一次。大招耗 100 TP 并占用行动，不耗 MP；大招、持续伤害、追击和无效指令不提供行动 TP。TP 跨战、旅行、休息、转职保留，倒地清零。自动大招默认关闭，可在战术页逐人开启；全队协奏独立。

终端「六地见闻」追踪 12 处建筑及 24 处细节。公会草药 3 换金币 18／旅人经验 20，港口矿石 2 换金币 14／经验 20，均限一次。灰炉首份巡路者短刃订单额外经验 10，可追认既有制作；林屋与观星城研究各经验 15 一次。天球塔提供 TP 演练，守灯会馆保留觉醒档案；训练不产生永久资源或 TP。

短特效由独立事件层播放：普通行动约 0.55 秒，大招约 0.9–1.1 秒；界面刷新不重播，演出期间不能重复提交。设置「减少动效」保留约 0.12 秒命中、治疗和状态提示。

## 存档与构建

战斗规则 v2 区分分来源护盾、敌方韧性与主属性克制；战中「变阵」消耗一次行动，每轮最多一次。羁绊与协奏需要玩家决策，精英及首领请先观察意图和弱点。旧档升级前自动保存 before-combat-v2 备份，进行中的战斗保留实际资源和随机状态。

新增十张日式西幻手绘加载图（六区域、四通用），配置为 data/loading.json。30 个补充物品及战斗符号使用 CC BY 3.0；LICENSE-Icons-CC-BY-3.0.txt 与 data/item-icons.json 提供作者及逐项来源。

格式 ashen-frontier-godot-desktop v1，专用用户目录 AshenFrontierDesktopGodot，自动档和三个手动档位位于 user://saves/。首次升级旧档保留 before-tp-v1 原始备份，缺失 TP／觉醒／建筑／自动大招字段补默认值，非法数值拒绝加载。支持原生 JSON 导入导出。

Web 版保持相同 JSON 格式，在当前浏览器的 IndexedDB 中保存进度，刷新后可继续；与 Windows、其他浏览器、隐私窗口及退役网页的进度隔离。清除网站数据会移除存档，可在存档菜单主动下载 JSON 备份或选择文件导入。

PowerShell 中设置 GODOT_PATH 后执行 ./build.ps1 -Action test 或 ./build.ps1 -Action export。导出需要对应版本 Windows 模板，输出 build/windows/灰烬边境.exe 和同名 PCK。当前原生工程可单独复制，运行与构建不引用父目录素材。

assets/ui/branding/ 保存原创星轨 SVG、透明 PNG 与多尺寸 ICO。assets/characters/ 保存全身立绘与八向运行帧，data/movement.json 定义朝向与动画。原生内容以 data/content.json、data/narrative.json、data/progression.json 和区域 JSON 为准；原文与新增内容分别使用独立基准。

游戏 CC0、Godot MIT、字体 OFL、第三方 CC0 及图标 CC BY 3.0 署名随 Windows 包和 Web 网站提供。addons/godot-mcp 仅用于开发，Windows／Web 导出均排除 addons/、tests/ 和 authoring/。开发运行时桥仅在编辑器引擎且 ASHEN_DEV_BRIDGE=1 时加载。
