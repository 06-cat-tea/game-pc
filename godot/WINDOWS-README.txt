解压整个文件夹，双击 灰烬边境.exe。灰烬边境.exe 和 灰烬边境.pck 请保持在同一目录。
运行不需要 Godot 编辑器、Node.js 或联网。

WASD / 方向键按屏幕八方向移动，Shift 以 1.8 倍速度跑步，F 交互，按住 Tab 打开快捷轮盘。
轮盘打开时鼠标自动居中；移动鼠标选择高亮图标，松开 Tab 执行。中央松开、Esc 或切换窗口取消。
Esc 打开终端或逐级返回；面板内 Tab 切换焦点。
B 背包、C 角色、J 任务、M 地图、L 队伍；同键关闭，其他菜单键切换页面。
战斗 1–4 选技能，E 选择首个已配置技能，Q 选择大招，点击目标、Enter 确认，Esc 暂停。
对白点击或按 Enter 补全、翻页，读完后选择。设置支持减少动效。

药草3与矿样2可用已有库存，在交付时扣除；公会药草清单与原建筑服务共用一次奖励。
